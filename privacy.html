隐私政策 (Privacy Policy)

🔒 艾可云核心承诺：严格的零使用日志（Strict No-Logs Policy）

艾可云郑重承诺：我们绝不追踪、绝不记录、绝不存储、绝不向任何第三方提供或出售用户的任何网络使用活动日志。 您的隐私是神圣不可侵犯的基本权利。

一、我们不收集的信息（绝无例外）

在您通过艾可云专线网络传输数据期间，我们的服务器架构在技术层面上已剥离了记录机制：

  • 不记录浏览记录： 我们从不记录您访问的任何具体网址、域名、页面或 API 请求；
  • 不记录数据流内容： 所有通过节点的数据均经过端到端加密，我们无法亦绝不刺探您上传或下载的具体文件与数据包内容；
  • 不记录 DNS 查询历史： 艾可云专线自带加密 DNS 递归解析系统，不生成任何查询日志；
  • 不记录用户源真实 IP 映射： 不存储用户真实网络 IP 与目标网络行为之间的关联关系；
  • 不保留会话连接时间戳： 不针对用户个人生成具体的上网持续时间或详细起止日志。

二、我们仅为维持账单运行所收集的最少必要数据

为确保账号认证以及计算套餐余量，我们仅在网站业务层保留维持服务所不可或缺的最简要素：

  • 注册账户凭证： 您注册时填写的电子邮箱地址（用于登录认证、接收密码重置邮件与关键服务通知）；
  • 套餐流量总额统计： 当前计费周期内已消耗的总字节数（Byte），仅用于在达到套餐阈值时暂停网络传输，不包含任何流量构成明细；
  • 支付交易凭据： 由合规第三方支付网关回传的订单交易编号与支付状态，我们自身绝不触碰和存储您的银行卡密码或支付账户敏感隐私。

三、纯内存（RAM-Only）运行与数据物理安全

艾可云的核心接入节点与加速集群均已全面推行无盘（RAM-Only）服务器部署。所有的操作系统与处理进程全部在易失性随机存取内存中运行，节点机箱内未挂载任何用于持久化日志的物理机械硬盘或闪存介质。一旦节点例行重启或断电，内存数据瞬间荡然无存，从物理源头上杜绝了数据被截获或提取的可能。

四、Cookie 与第三方技术说明

艾可云主站及用户中心仅使用最基本的会话 Cookie（Session Cookie）用以维持您的登录会话状态。本站不引入任何第三方的广告追踪像素（Pixel）或行为画像工具，确保您的访客数据完全干净独立。

五、隐私政策的更新

我们可能会适时更新本隐私保护准则，以反映技术演进或合规要求的提升。任何改动均会在此页面公布。若您对艾可云的数据保护与隐私政策有任何疑问，可随时通过用户中心工单向我们的数据安全顾问咨询。
